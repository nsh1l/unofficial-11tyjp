# Eleventy v3とBuild Awesome v4の違い

**Build Awesome v4は開発中です。** このガイドの本文とコード例は、安定版のEleventy 3.1.6を対象にしています。v4を試す場合は、次の違いを先に確認してください（2026年10月時点）。

## 名前と動作環境が変わる

[改称の公式発表](https://www.11ty.dev/blog/build-awesome/)では、Eleventyの次の大きな版をBuild Awesome v4として案内しています。別の製品に乗り換えるわけではありません。ただし、v3の手順をv4にそのまま使えるとは限りません。

- **このガイドで扱うv3**：[Eleventy 3.1.6](https://www.11ty.dev/docs/) は `@11ty/eleventy` を使い、Node.js 18以上が必要です。導入方法は[環境構築](/setup/)にあります。
- **開発中のv4**：[Build Awesome v4](https://build.awesome.me/docs/) は `@awesome.me/buildawesome` を使います。このページで扱うプレリリース版はNode.js 22.15以上が必要です。

公式は既存プラグインやビルドコマンドとの互換性を保つ方針を示しています。ただし、使っているプラグインがプレリリース版で動くかは手元で試してください。

## WebCはどちらもプラグインを使う

v3では[WebCの公式プラグイン](https://www.11ty.dev/docs/languages/webc/)を追加します。v4でもプラグインが案内されていますが、試す際は[v4のWebC文書](https://build.awesome.me/docs/languages/webc/)を参照してください。v3向けの設定例は[WebCの使い方](/templates/webc/)にあります。

## インストール時はプレリリース版を明示する

[v4の公式ドキュメント](https://build.awesome.me/docs/)は `@awesome.me/buildawesome` を案内しています。プレリリースを試す場合は、インストール時に版を指定します。

```sh
# Node.js＋npm
npm install --save-dev @awesome.me/buildawesome@4.0.0-alpha.10
npx @awesome.me/buildawesome

# Bunでパッケージを管理する場合
bun add -d @awesome.me/buildawesome@4.0.0-alpha.10
bunx buildawesome
```

このBunの例はパッケージのインストールとコマンドの起動にBunを使うものです。Bunランタイムでの動作保証ではありません。v4の公開パッケージはNode.js 22.15以上を要求します。`node --version` で確認してください。

既存サイトを直接更新せず、別ディレクトリか別ブランチで試してください。v3のビルドと主要URLを比べ、プラグインも確認してから移行を判断します。プレリリースの出力をそのまま本番に上書きしないでください。手順は[現行のv4文書](https://build.awesome.me/docs/)でも確認してください。
