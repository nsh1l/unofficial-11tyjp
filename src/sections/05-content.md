# データとコンテンツ

記事の本文はMarkdownファイルに書きます。見た目はレイアウトで管理するので、記事を書くたびにHTMLを触る必要はありません。

## 原稿の先頭に必要な情報を書く

ファイルの先頭にタイトルや日付を置き、その下に本文を書きます。日付を公開日として使うか更新日として使うかは、サイト内で揃えておきましょう。ファイル名やURLは公開後に変えるとリンク切れの原因になります。

```md
---
title: はじめての記事
date: 2026-10-02
tags: [posts]
layout: base.njk
---
# はじめての記事

ここから本文です。
```

`tags: [posts]` を付けた原稿は、あとで記事一覧に集められます。こうして本文とは別に書く情報を[フロントマター](https://www.11ty.dev/docs/data-frontmatter/)と呼びます。

## 一覧は原稿から作る

`posts` タグの記事は `collections.posts` で取り出せます。Nunjucksで一覧を書くなら、例えばこうです。

```njk
<ul>
{% for post in collections.posts %}
  <li><a href="{{ post.url }}">{{ post.data.title }}</a></li>
{% endfor %}
</ul>
```

記事を追加すると、一覧にも反映されます。ただし、これだけで日付順に並んだり、下書きが自動で除外されたりはしません。順序は[コレクションの仕様](https://www.11ty.dev/docs/collections/)に沿って設定し、下書きが出ていないかビルド結果を確認してください。

## 共通情報は一か所へ

サイト名など、どのページでも使う値は[グローバルデータファイル](https://www.11ty.dev/docs/data-global/)に置けます。記事ごとのタイトルは原稿に残しておくほうが、ファイルを開いたときに分かりやすくなります。

公開前には原稿を読み返し、プレビューで見出しとリンクを確かめてください。AIに校正を頼んだ場合も、固有名詞とリンク先は自分で確認します。
