# Eleventy / Build Awesome 日本語ガイド

Eleventy / Build Awesomeを日本語で学ぶための非公式コミュニティガイドです。

## 開発

このサイト自体はEleventy 3系で構築しています。Node.js/npmとBunの手順を本文で同等に案内する予定です。作業ツリーではBunを使います。

```sh
bun install
bun run start
```

ビルドと生成結果の簡易チェック:

```sh
bun run check
```
