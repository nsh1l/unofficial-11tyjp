# Build Awesome v4を試す前に

**このページはプレリリース版の情報です。** 普段使うサイトを作るなら、まず[安定版の導入手順](/setup/)でEleventy 3.1.6を試してください。v4は名称だけでなく必要なNode.jsの版やパッケージ名も変わります。以下は2026年10月時点の案内で、正式版の手順を保証するものではありません。

[公式の改称発表](https://www.11ty.dev/blog/build-awesome/)は、Eleventy v4がBuild Awesome v4になると説明しています。既存のプラグインやビルドコマンドとの互換性を維持する方針ですが、個別の組み合わせは自分のプロジェクトで確認してください。

## インストール時はプレリリース版を明示する

[v4の公式ドキュメント](https://build.awesome.me/docs/)は `@awesome.me/buildawesome` を案内しています。パッケージの既定タグだけを頼らず、試す版を明記します。

```sh
# Node.js＋npm
npm install --save-dev @awesome.me/buildawesome@4.0.0-alpha.10
npx @awesome.me/buildawesome

# Bunでパッケージを管理する場合
bun add -d @awesome.me/buildawesome@4.0.0-alpha.10
bunx buildawesome
```

この節のBunコマンドは、Bunのパッケージ管理・コマンド実行に沿った例であり、Eleventy側がBunランタイムでの動作を保証する意味ではありません。v4の公開パッケージはNode.js 22.15以上を要求します。実行前に `node --version` を確認してください。

試すなら既存サイトとは別のディレクトリやブランチで。生成したURLとHTMLを安定版と比べ、使っているプラグインを一つずつ確認します。**プレリリースの結果を、そのまま本番サイトに上書きしない**ことが大切です。[v4の現行ドキュメント](https://build.awesome.me/docs/)を最後に読み直してください。
